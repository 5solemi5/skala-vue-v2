# 오늘의 채비

> 같은 하늘, 다른 하루

날씨앱은 "내일 비 20mm" 까지만 알려준다. 그다음은 각자 알아서 판단해야 한다.
그런데 같은 예보를 보고도 준비해야 하는 건 하는 일마다 다르다.

| 오늘 날씨 | 정비소 (자동차 정비) | 밭 (농사) |
|---|---|---|
| 습도 88% | 도장 걸면 백화가 생긴다 → 오늘은 미룬다 | 잎에 물기가 오래 남는다 → 곰팡이병 조심 |
| 최저 2℃ | 배터리 방전 출동이 몰린다 → 재고 확인 | 서리 위험 → 오늘 밤 피복하거나 수확을 앞당김 |

| 오늘 날씨 | 출퇴근길 (자전거) | 주말 경기 (야구) |
|---|---|---|
| 강수확률 70% | 노면이 젖으면 제동 거리가 늘어난다 → 두고 간다 | 우천 취소 가능성 → 표를 미리 정리한다 |
| 풍속 8m/s | 옆바람에 중심을 잃는다 → 오늘은 아니다 | 뜬공 판단이 어려운 날 |

챙길 수 있는 일은 일곱 가지다.
**자동차 정비소 · 농사 · 현장 작업 · 자전거 · 등산 · 야구 · 빨래·환기**

같은 숫자를 하는 일에 맞춰 다르게 읽어주는 게 이 서비스다.

**왜 만들었나** — 가까운 분들 중에 날씨로 하루가 달라지는 일을 하시는 분들이 있다.
두 분 다 아침마다 날씨를 확인하시는데 어느 앱도 "그래서 오늘 뭘 하시라" 는 말은 안 해준다.
매일 전화로 물어볼 수도 없어서 대신 봐 주는 화면을 만들기로 했다.
만들다 보니 날씨로 하루가 바뀌는 사람이 두 분만은 아니었다.

## 기능

**1. 하늘이 보이는 창**
판정 카드 맨 위에 지금 보고 있는 지역의 하늘이 한 칸 잘려 있다.
장식이 아니라 데이터다. 전주에 비가 오면 창밖이 전주의 강수확률만큼 내리고,
구름이 88% 면 하늘이 그만큼 덮이고, 풍속 8m/s 면 그 속도로 흐른다.
해는 그 지역의 실제 일출·일몰 시각을 따라 뜨고 진다.
지역을 바꾸면 창도 같이 바뀐다.

**2. 열두 개의 판**
하늘은 에디션으로 나뉜다. `#000 AUJOURD'HUI` 는 실제 날씨를 따라가고,
나머지 열하나는 언제 봐도 그 하늘이다 — 오디세이아, 자오선, 악의 꽃,
야상곡, 극광, 폭풍우, 겨울, 잔불, 고래, 먹, 박하.

판을 고르면 배경만 바뀌지 않는다.
액센트 색과 지면 톤, 표제 서체, 그리고 판마다 붙은 제사 한 줄까지 같이 바뀐다.
표지만 갈아 끼우고 속이 그대로면 고른 보람이 없다.
세기·빠르기·결은 어느 판을 골랐든 그 위에 얹어 손볼 수 있다.

**3. 오늘의 채비**
기온, 날씨, 습도, 강수확률, 풍속을 먼저 보이고
`오늘은 아니에요` / `조심하세요` / `괜찮아요` 중 가장 무거운 것을 앞세운다.
왜 그런 판정인지 근거를 함께 적는다 (`습도 88% — 도막에 수분이 물려 백화가 생깁니다`).

**4. 시간축**
앞으로 18시간. 막대 높이는 기온, 칠은 판정, 아래 줄은 비 올 확률이다.
나가도 되는 구간은 축 위에 띠로 그리고 그 안에 시각을 적는다.
첫 칸이 지금이고 눈금은 세 시간마다 적는다.
막대를 누르거나 좌우 화살표로 옮기면 그 시각의 값이 제목 줄에 나온다.
마땅한 때가 없는 날은 없다고 적는다.

**5. 챙기는 사람들**
이름과 하는 일, 지역을 넣어 열두 개까지 등록한다.
대상마다 지역이 따로라서 멀리 떨어진 곳도 함께 볼 수 있다.
카드는 레코드 뒷면의 수록곡처럼 번호가 앞에 서고 아래에 좌표가 새겨진다.

**6. 마당**
챙기는 사람 수만큼 캐릭터가 걸어다니는 삽화.
무대는 들판·바닷가·밤하늘·눈밭·골목 다섯 가지다.

**7. 다른 지역**
목록 위 한 줄로 전체 상황이 먼저 읽힌다 (`7곳 중 4곳은 오늘 피하시는 편이 낫습니다`).
제목 줄의 돋보기로 이름을 걸러 볼 수 있다.

**8. 지역 검색**
한글로 검색되고 동명이지는 지역명으로 구분해 보여준다 (`광주` → 광주광역시 / 경기 광주시).
지오코딩 API 두 곳을 함께 검색해서 한쪽에만 있는 지역(철원, 영월 등)도 찾을 수 있다.

**9. 낮 / 밤 / 자동**
`자동` 은 기기 설정을 따라간다. 값이 셋인 건 두 개짜리 스위치로는
시스템을 따라가는 상태로 되돌아갈 수가 없기 때문이다.

**10. 단위 · 언어**
℃ / ℉ 와 한 / EN. 화면 문구와 판정 문구, 판정 근거의 기온까지 한꺼번에 바뀌고 저장된다.
화씨로 보는데 근거만 섭씨면 앞뒤가 안 맞는다.

**11. 지금 있는 곳**
들어오자마자 위치를 묻지 않는다. 무슨 사이트인지 알기도 전에 권한 팝업이 뜨면
일단 거절하게 되고, 한 번 거절하면 브라우저 설정을 열기 전까지 되돌릴 수 없다.
이미 허용해 둔 브라우저에서만 Permissions API 로 확인한 뒤 조용히 불러온다.

## 만들면서 정한 것

**배경은 데이터여야 한다.**
배경을 장식으로 만들면 화려해도 곧 지겨워진다. 매일 열고 싶어지는 건
창밖이 실제로 지금 그곳의 하늘일 때다. 화려함이 곧 정보가 되면
"신비롭다" 와 "유익하다" 가 서로 싸우지 않는다.

**하늘은 창이지 벽지가 아니다.**
화면 전체에 깔지 않았다. 판정을 읽으러 오는 화면이라
글자 뒤에서 계속 움직이는 것이 있으면 읽는 내내 시야 구석이 시끄럽다.
한 칸으로 잘라 두면 볼 때 보고 읽을 때는 안 본다.

**셰이더는 하나, 값만 갈아 끼운다.**
배경을 여러 가지로 고르게 하려고 셰이더에 `if` 를 늘어놓으면
고르지도 않은 하늘의 계산까지 픽셀마다 따라다닌다.
색과 세기를 전부 uniform 으로 빼서, 판을 하나 더 만드는 값이 거의 0 이다.
사용자가 손잡이를 돌려 만든 하늘도 프리셋과 똑같은 모양의 숫자 묶음이다.

**판정 색은 판을 타지 않는다.**
액센트는 펼친 판마다 달라져서 밑줄과 테두리와 좌표 각인까지 물들이지만,
빨강·주황·초록 세 가지에는 쓰지 않는다.
그 셋은 어느 판을 펼쳐도 같은 뜻이어야 한다.

**판정은 아이콘이 아니라 글자로.**
아이콘만으로는 "하지 마세요" 와 "조심하세요" 가 구분되지 않는다.
반대로 해와 달은 서로 닮은 데가 없어서 그림으로 둬도 된다.

**문구는 규칙에서 떼어 냈다.**
판정 규칙 파일에 조건과 문장이 같이 있으니 언어가 둘이 되면서
규칙 하나에 문장이 둘씩 붙어 조건이 안 보였다.
규칙은 키만 넘기고 문장은 언어 파일에서 찾아 쓴다.

**낮과 밤은 한 곳에서만 다룬다.**
`자동` 을 CSS 의 `prefers-color-scheme` 에 맡기면 어두운 상태를 가리키는
선택자가 두 개가 되고, 색 한 벌을 두 번씩 적어야 한다.
실제로 하늘 색을 손보면서 한쪽만 고치는 일이 생겼다.
JS 에서 미리 풀어 `<html data-theme>` 에 확정값만 적으니 선택자가 하나로 줄었다.
첫 그림이 번쩍이는 건 `index.html` 의 짧은 스크립트가 막는다.

**좌표는 장식이 아니다.**
카드에 새긴 위도·경도는 그 창에 보이는 하늘을 어디서 올려다본 것인지를 밝히고,
같은 이름의 지역(광주광역시 / 경기 광주시)을 가른다.

**열두 개까지만.**
아침에 한 번 훑어보는 화면이라 한눈에 들어오는 만큼만 둔다.
더 늘리면 카드가 작아지고 결국 스크롤하게 되는데, 그러면 한눈에 본다는 목적이 사라진다.

## 실행

```sh
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run build
```

OpenWeatherMap 키가 필요하다. 루트에 `.env.local` 을 만들고 넣는다.

```
VITE_OPENWEATHER_API_KEY=발급받은키
```

`.env.local` 은 `.gitignore` 의 `*.local` 에 걸려 커밋되지 않는다.

## 배포

Vercel. `main` 에 푸시하면 자동으로 다시 빌드된다.

**하위 주소가 404 나지 않게 미리 막았다.**
라우터가 history 모드라 주소창에 `/about` 을 직접 치면 브라우저가
서버에 그 경로를 그대로 요청한다. 개발 서버는 못 찾으면 `index.html` 을
돌려주도록 되어 있어서 로컬에서는 드러나지 않는 문제다.

```json
{ "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }] }
```

**환경변수는 빌드 전에 넣어야 한다.**
`import.meta.env.VITE_...` 는 실행 중에 읽는 값이 아니라 빌드할 때 문자열로
바뀌어 들어간다. 배포한 다음에 키를 등록하면 이미 만들어진 번들에는 반영되지
않아서 다시 빌드해야 한다.

그래서 키가 결과물 안에 그대로 들어간다. `VITE_` 를 붙인 값은 전부 공개된다고
보는 게 맞고, 감춰야 하는 키라면 서버를 하나 두고 거기서 부르는 게 맞다.
이번엔 무료 플랜 날씨 키라 그대로 뒀다.

## 사용한 것

Vue 3 (Composition API) · Vue Router · Pinia · Axios · Vite · Tailwind CSS v4

배경은 WebGL 프래그먼트 셰이더를 직접 썼다.
three.js 는 600KB 가 넘는데 여기 필요한 건 화면 덮는 사각형 하나와 셰이더 하나뿐이라
씬 그래프도 카메라도 지오메트리도 쓸 데가 없었다.
외부 라이브러리 없이 `skyShader.js` 와 `SkyCanvas.vue` 두 파일로 끝난다.

한/영 전환은 `vue-i18n` 없이 스토어 값 하나와 문구를 찾아 주는 함수로 만들었다.

API 는 두 곳을 쓴다.

- **OpenWeatherMap** — 현재 기온, 날씨 상태, 습도, 풍속, 구름양, 일출·일몰, 아이콘
- **Open-Meteo** — 오늘 최저기온, 시간대별 기온·강수확률·습도·풍속 (키 불필요)

OpenWeatherMap 무료 플랜에 오늘 강수확률과 일 최저기온이 없다.
그게 없으면 방제·서리 판정을 못 해서 Open-Meteo 를 같이 부른다.

```
src/
├── api/weatherApi.js       두 API 를 합쳐 화면이 쓸 형태로 만든다

│   ├── configStore.js      단위 · 하는 일 · 언어 · 낮밤 · 마당 배경

│   ├── cityStore.js        내 지역 목록
```
